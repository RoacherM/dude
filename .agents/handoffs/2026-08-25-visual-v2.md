## 已完成

改动全部集中在两个文件：

- `design/prototype/index.html` — token 层重写 + 组件层重排
- `design/prototype/fonts.css` — 追加 Archivo latin 子集（variable，34KB woff2 → base64）

### 1. 浮岛外壳

`.app` 加 `padding: var(--db-gap)`，三列共用 `.column`：
`background: --db-panel` + `1px solid --db-line-panel` + `border-radius: 20px`。
拖拽把手宽度改成 `var(--db-gap)`，正好占满列间那条缝；默认无线，hover / 拖拽时
显示 2px 蓝色指示（新增 `.dragging` class，在 `trackDrag()` 里加/摘）。
`.app.dock-max .dock` 的 `inset: 0` → `inset: var(--db-gap)`，否则铺进窗口内边距。

### 2. 字体

56 处正文字体栈 + 7 处 mono 字体栈批量替换为 `var(--db-font)` / `var(--db-mono)`
（含全部 `--dsw-font-*` 与 `--dsw-font-family`），然后重定义：

```
--db-font      Archivo + PingFang SC 回退   正文
--db-brandfont Departure Mono               只有侧栏字标 + hero wordmark
--db-mono      ui-monospace                 路径 / 模型 ID / 终端 / 代码 / 统计行
```

**这条推翻了此前「Departure Mono 全局、勿改回」的偏好**，是用户在本次会话中
明确选择「按重设计：Archivo 正文」的结果。

### 3. 双色分工

- 红 `--db-brand #ec3013` = 品牌：侧栏字标点、会话行选中左条、设置分区选中左条
  （都用 `box-shadow: inset 2px 0 0`）
- 蓝 `--db-primary #679efe` = 行动：发送键实心底、`:focus-visible` 环、菜单选中勾
- 绿 `#3ecf8e` 运行 / 橙 `#e9a23b` 等待，走会话行 `::before` 状态点，
  由 `data-state="run|await"` 驱动，默认灰

### 4. 结构调整（视觉层）

- 视图 Tab（对话/轨迹）从独立一行收进主列状态栏，做成分段控件 → 主列多出 38px
- 侧栏字标行：折叠按钮从左侧移到最右；「新建任务」标签左对齐、＋ 压右缘（Modernist）
- 「工作区」→「工作空间」，小号 + 0.1em 字距
- 设置行进 `.settings-shelf`（顶部留一道缝），带 `⌘,` 提示
- Hero：logo / Departure Mono 字标 / slogan 三段竖排
- 消息：user 泡 `16/16/4/16`；上下文与 Think 行改成 1px 描边卡；轨迹改时间轴
- 终端 / 文件预览 / 浏览器内容区改成嵌进面板的 `#0e0e10` 圆角黑块

### 5. 用户验收提的两点（已改）

- **全屏 / 退出全屏图标不成对**：`#i-max` 原来是两个对角箭头，`#i-min` 是四角括号，
  两个图标家族。都换成 Lucide `maximize` / `minimize`（四角括号，朝外 vs 朝内）。
- **主列和停靠栏各有一颗 dock 开关，同时可见**：违反 DESIGN_INTENT §4「右列开关归右列
  状态栏」。`applyLayout()` 里给主列的 `#toggleDock` 加了 `.hidden` 切换——停靠栏开着
  时只留它自己的收起键，与左列 收起/展开 的分工对称。规则已写进 §3 的表。
  （注：`plugins/deepbuddy/src/client/app/App.tsx` 的 `DeepBuddyDockToggle` 本来就是
  对的，是原型漏了这条。）
- **红左条不要用来标选中**：先去掉设置分区的，再去掉会话行的。品牌红收到只剩侧栏字标
  那一颗方点；所有列表选中态一律只靠底色。§10 已按最严的口径重写。

### 6. 顺手修的 bug

`轨迹` tab 在改动前就是**空白**的：`.conversation` 与 `.trace` 都在正常流里且
`height: 100%`，conversation 把 trace 顶到视口外。已改为两者都
`position: absolute; inset: 0` 叠放。
