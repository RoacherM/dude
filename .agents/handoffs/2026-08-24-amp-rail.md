### B. 真实 PTY 终端

- client：
  - `plugins/deepbuddy/src/client/features/terminal/index.ts`
  - `plugins/deepbuddy/src/client/features/terminal/TerminalView.tsx`
  - `@xterm/xterm@6.0.0` + `@xterm/addon-fit@0.11.0` 内联进 client bundle。
  - `plugins/deepbuddy/build.mjs` 用 `.css: text` 内联 xterm CSS；组件挂载局部 `<style>`。
  - xterm 主题读取 `--db-window` / `--db-text-*` / `--db-mono`；`ResizeObserver + FitAddon` 回传 cols/rows。
- host：`plugins/deepbuddy/src/host.js`
  - `webServer.registerUpgrade()` 注册 `/deepbuddy/terminal`，由 `ws@8.21.3` 处理 WebSocket。
  - 连接先用既有 `resolveSessionCwd()` 验证 `sessionId`，并校验浏览器 Origin 与 Host 同源；未知会话不能 spawn。
  - `DeepbuddyTerminalManager` 以 `sessionId` 为键，保证每个会话至多一个 `node-pty@1.2.0-beta.15` 实例。
  - cwd = 会话记录的工作区根；shell = `$SHELL`，缺失时 `/bin/zsh`。
  - host 保留最新 64KB UTF-8 scrollback；前端重新挂载时收到完整 snapshot。
  - 关闭 dock / 切换分段只断 WebSocket attachment，不杀 PTY；显式「终止终端」、`session/disposed`、插件卸载才清理资源。
- 协议：

```text
WS /deepbuddy/terminal?sessionId=<id>

client -> host: input { data } | resize { cols, rows } | kill
host -> client: snapshot { data, cwd, status } | output { data }
               | exit { exitCode, signal } | closed | error
```
