## A. Token 统一（tokens.ts，杠杆点）

用 getComputedStyle 反查官方 3080 实际引用的 dsw 变量（不问名字猜），把
`tokens.ts` 每个 `--db-*` 改为 `var(--dsw-alias-*, fallback)`：

- 底色：`--db-window`→`--dsw-alias-bg-base`(#151517)、`--db-rail`→
  `--dsw-specific-sidebar-fill`(#1b1b1c)、`--db-popover`→
  `--dsw-specific-menu`(#353638)、`--db-dialog`→`--dsw-specific-menu`(#2c2c2e)。
- 文本五阶：`--db-text`→`label-primary`(#f9fafb)、`--db-text-2`→
  `label-secondary`(#cfd3d6)、`--db-text-3`→`label-tertiary`(#adb2b8)、
  `--db-text-4`→`label-caption`(#81858c)、`--db-text-5`→caption
  `color-mix 78%`。
- hover/选中：`interactive-bg-hover`(#ffffff14)/`interactive-bg-active`(#ffffff24)。
- 边框：`border-l1`(#ffffff0f)...`border-l4`(#fff3)。
- 语义：`--db-primary`→`--dsw-alias-state-business-primary`(#679efe)、
  `--db-run`→`--dsw-alias-state-success-primary`(#22c55e)、`--db-await`→
  `--dsw-alias-state-warning-primary`(#d97757 fallback)、`--db-offline`→caption。
- 字体栈：直接照抄官方 body font-family。
- 半径：行 8px / 卡片 22px（官方 sessionRow radius 8px、card 22px）。
- 动效：`--ds-transition-duration-fast(.1s)/normal(.2s)` +
  `--ds-ease-in-out(cubic-bezier(.4,0,.2,1))`。
- 滚动条：改用官方 `--dsw-alias-scrollbar-bg-l2(#545557)/hover-l2(#65676b)`，
  宽 8px。

`kit.tsx` 里写死的颜色改为 token 引用：primary 按钮 bg/文字、
switch off bg、knob、select field bg、status pill 边框、Tabs 背景、
SettingRow 分隔线。`icons.tsx` 加 `FolderOpen` 图标（工作区展开态）。

## B. 侧栏结构对齐（SessionList.tsx + ThreeColumnFrame.tsx）

- 顶行：品牌 wordmark 移入 ColumnFrame header（与收起按钮同行，16px/600），
  macOS 红绿灯保留；slogan 收敛为 label-tertiary 12px 小字在 body。
- 「新建任务」→ 官方 pill 样式：全宽、bg `var(--dsw-alias-bg-raised, #43454a)`、
  radius 12px、h 38px、14px/500、图标+文字居中（文案保留「新建任务」）。
- 分区 header：「工作区」（对齐官方，非「工作空间」）；点搜索图标变行内输入框。
- 工作区组行 → 官方 tree 形态：Folder/FolderOpen 开合两态图标（去 chevron、
  去计数徽标）。
- 会话行：去主题圆点、缩进、短时间（fmtRel 改为官方 `X分钟/X小时/X天`，
  去空格/「前」）、当前会话圆角填充 pill（KIT.Row current 用
  `var(--db-fill-2)` = 官方 0.08 白）。运行中用绿点 + `--db-run-soft`。
- 「显示更多会话（N）」→ 官方文案「展开其余 N 个会话」（TreeGroup 渲染）。
- 「未分组」：从独立 GroupLabel 改为与工作区组同级的可折叠 TreeGroup。
- 保留扩展 override map（`expanded` state）：当前会话组默认展开，用户手动
  折叠优先。

## C. Hero 品牌 lockup（adapter.ts DeepBuddyBrandMark）

- `DeepBuddyBrandMark`（`conversation.hero.brand.mark`，priority -1）改为
  26px/600 wordmark，与官方 headline（26px/500）同基线、~14px 间距。
- **约束（如实记录）**：官方 hero 的 brand 列是固定 `34px` grid cell，
  「DeepBuddy」wordmark 任何可读字号都会溢出该 cell 叠进 headline
  （26px 时重叠 ~34px、20px 时 ~19px）。且官方 `hero.headline`/`preview` 是
  硬编码 `t("hero.headline")`，`conversation` locale 单 occupant——
  接管会打崩 ui-conversation（实测 `already has locale "zh"`）。故 wordmark
  按任务 spec 放大为 26px lockup，叠进 gap 是刻意 lockup 而非排版事故；
  已截两版（`uiw-hero-variantA.png` 纯放大版 + `uiw-hero.png`）。
- DeepBuddy slogan 已在侧栏 brand 行保留。
