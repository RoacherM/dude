# 原型全量接线（v2）：消灭死按钮，对齐真实交互逻辑

## 用户反馈（原话）

「不能交互，目前很多按键的功能点击没有反应，和目前的实现逻辑还是不一样的」

验收方实测确认：原型 27 个 button 中大量未接线；全页仅 1 个元素有
`cursor: pointer`（真实产品几乎所有可点元素都有手型+hover 态）；
只有主演示链路（分段切换/拖拽/地址栏/终端输入）可用。

## 铁律

**出现在界面上的每一个可点控件，要么按下面的规格真实响应，要么给出
disabled 视觉（降低不透明度 + cursor: default）。零静默死点。**
所有可交互元素补 `cursor: pointer` 和 hover 态（参考产品 .dbdy-hv 的
fill 变化）。逻辑以 `plugins/deepbuddy/src/client/` 真实实现为准，
吃不准就去读对应源码。

## 控件规格（按区域）

### 侧栏（展开态）
- 收起侧边栏 → 折叠；折叠后交通灯+展开按钮移到主栏左上同一水平线（已有）。
- 新建任务 → 主栏切 hero 页；dock 与 dock 按钮同时消失（sessionStarted
  规则，见 ThreeColumnFrame）。
- 搜索 → 弹出内联搜索框，输入实时过滤会话行；Esc/失焦关闭还原。
- 视图选项 / 添加工作区 → 弹小型假菜单（2-3 项，点外部关闭；菜单项点了
  显示 toast「原型占位」）。
- workspace 组头 → 折叠/展开该组会话。
- 每一条会话行 → 高亮该行 + 主栏切到该会话；至少 3 个会话有各自不同的
  假对话内容（其余可复用通用内容但标题/高亮必须正确切换）。
- 「展开其余 N 个会话」 → 展开显示更多假行，文案变「收起」。
- 设置 → 假设置弹层（遮罩 + 面板，含 2-3 个假分组行；Esc/点遮罩关闭）。

### 主栏（会话态）
- 对话 / 轨迹 tab → 真实切换；轨迹页做一个假的步骤时间线（3-4 条工具/
  思考步骤行）即可。
- 消息操作行：复制 → 实际写剪贴板 + toast；赞/踩 → 互斥 toggle 高亮；
  分叉/更多 → 假菜单或 toast。用户气泡的复制同理。
- composer：
  - 输入框可输入；有内容时发送按钮变为可用态（空内容 disabled 视觉）。
  - 发送 → 追加用户气泡 + 300ms 后追加一条假助手回复，滚动到底。
  - ＋ 附件 → 假菜单（文件/图片 2 项 + toast）。
  - 权限下拉（Ask first / Full access…）→ 真下拉可选，选中回显。
  - 模型下拉 → 真下拉（列 2-3 个假模型），选中回显。模型名与截图一致用
    「DeepSeek-V4-Flash-Vision-Exp · High」。
  - 底部统计行静态即可。

### 主栏（hero 态）
- workspace chip、模式 chip → 真下拉可选。
- composer 同上；发送 → 创建「新会话」进入会话态（侧栏出现新行并高亮）。

### dock
- 打开/关闭按钮、⌘J 快捷键（会话态才可用）、全屏/退出、把手拖拽+双击
  （已有，保持）。
- 文件：树开合、文件预览 tab、tab ×（已有）；预览区滚动。
- 终端：多 tab +/×、输入回显（已有）；「重新启动终端」按钮 → 清屏重打
  假 prompt。
- 浏览器：多 tab +/×、地址栏（已有）；后退/前进/刷新必须基于每 tab 的
  假历史真实工作（可导航去过的页面）；外部打开 → toast；拒绝嵌入态：
  地址输入 x.com 或 baidu.com 时演示该态。

## Toast

做一个统一的轻量 toast（右下角 2s 消失），占位功能一律用它反馈，
不允许 alert()。

## 验收方式（验收方执行，先自查）

1. 每个状态（hero、会话、折叠侧栏、dock×3 视图）下运行变异检测普查：
   对每个可见可点元素 click 后 250ms 内必须有 DOM 变化，或该元素带
   disabled 视觉。零静默死点。
2. hover 任一可点元素必须有手型 + hover 反馈。
3. 行为抽查与真实 app 并排对比。
