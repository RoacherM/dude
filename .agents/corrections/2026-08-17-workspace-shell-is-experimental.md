# workspace-shell 是实验性插件，不是发行版必备

- 日期 / agent：2026-08-17 / claude
- 我原来的理解：workspace-shell（工作区抽屉）是精选插件、系统环成员，
  宪章可变性表里把它当作「精选插件」的代表例子。
- 用户实际要的：workspace-shell 是**实验性质**的（dsh-plugins 仓的产物），
  不是发行版必备；当前精选（收编）集合为空。发行版必备的是 deepbuddy-*
  一族本身。
- 分歧根源：范围假设——把「profile 里装着」等同于「发行版必备」。
  装在 profile 里 ≠ 收编进精选；收编是显式的发行版决策。
- 以后如何避免：插件进系统环（不可变集合）必须有显式收编记录
  （宪章可变性表 + profile 固定段注释），默认一切非 deepbuddy-* 插件
  都是应用环/实验性。宪章已更新。
