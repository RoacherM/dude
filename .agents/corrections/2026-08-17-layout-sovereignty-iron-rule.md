# 布局主权是铁律：外部插件永不修改 UI 布局，浮层不是开放面

- 日期 / agent：2026-08-17 / claude
- 我原来的理解：`shell.overlay` 自由浮层是开放面之一（宠物/浮动面板/终端浮窗
  等生态可自由定位），terminal-probe 浮窗是合格的生态形态展示。
- 用户实际要的：**iOS 模型**——外部插件只能在系统环框定的座位内渲染
  （抽屉 tab、设置页、工具视图、composer 按钮），位置/大小/开关全由发行版控制；
  自由定位的浮层可控性太差，不开放。具体功能开发可以让 dsh 给自己开发
  （创造模式），fable 负责验收。
- 分歧根源：范围假设——我把「生态兼容最大化」当默认目标，用户的优先级是
  「可控性 > 兼容面积」，拓展性本来就定义为「足够但非全部」。
- 以后如何避免：开放任何新面之前先过 I4 检查——**该面是否让插件获得
  位置/大小/几何的自主权？是则降为受控或保留**。宪章已落 I4 铁律 +
  shell.overlay 降为受控面（白名单）+ P4a.2 执行层任务。
